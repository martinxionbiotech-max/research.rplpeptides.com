# Peptide Radiolabeling

!!! info "Executive Summary"
    Bifunctional chelators (DOTA, NOTA) attach radioactive isotopes (68Ga, 177Lu, 99mTc) to peptide vectors for diagnostic PET/SPECT imaging and targeted radionuclide therapy (theranostics).
