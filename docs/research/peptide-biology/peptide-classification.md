# Peptide Classification

!!! info "Executive Summary"
    Peptides can be classified by length (oligopeptides, polypeptides), function (hormones, neuropeptides, AMPs, growth factors), structure (linear, cyclic, disulfide-rich), or synthesis route (ribosomal vs non-ribosomal).
