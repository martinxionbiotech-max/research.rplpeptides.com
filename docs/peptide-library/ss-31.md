# SS-31 / Elamipretide Profile

!!! info "Executive Summary"
    SS-31 (elamipretide) is a synthetic mitochondria-targeted tetrapeptide ($d\\text{-Arg-dmt-Lys-Phe-NH}_2$) that binds to cardiolipin in the inner mitochondrial membrane.
