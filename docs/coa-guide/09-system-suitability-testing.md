# System Suitability Testing (SST) in Peptide HPLC Analysis

!!! info "Executive Summary"
    System Suitability Testing (SST) confirms instrument performance (pump, column, detector) prior to running production batch samples.

## Standard Acceptance Criteria

- **Peak Area Repeatability**: $\\text{RSD} \\le 1.0\\%$ ($n = 5$ or $6$ injections)
- **Retention Time Repeatability**: $\\text{RSD} \\le 0.5\\%$
- **Tailing Factor ($T$)**: $T \\le 1.5$
- **Chromatographic Resolution ($R_s$)**: $R_s \\ge 1.5$ between critical pair
