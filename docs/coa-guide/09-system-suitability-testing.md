# System Suitability Testing (SST) in Peptide HPLC Analysis

SST confirms instrument performance (pump, column, detector) prior to running production batch samples.

## Standard Acceptance Criteria
- Peak Area RSD $\le 1.0\%$
- Retention Time RSD $\le 0.5\%$
- Tailing Factor $T \le 1.5$
- Resolution $R_s \ge 1.5$
