# Retention Time (RT) Explained: Capacity Factor, Selectivity, and Drift

Retention time ($t_R$) measures how long an analyte is retained inside the chromatographic column.

## Capacity Factor (Retention Factor) $k'$
$$k' = \frac{t_R - t_0}{t_0}$$

Where $t_0$ is column void time.
