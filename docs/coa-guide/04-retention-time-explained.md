# Retention Time (RT) Explained: Capacity Factor, Selectivity, and Drift

!!! info "Executive Summary"
    Retention time ($t_R$) measures how long an analyte is retained inside the chromatographic column. Capacity factor ($k'$) normalizes retention relative to system dead time ($t_0$).

## Capacity Factor (Retention Factor) $k'$ Formula

$$k' = \\frac{t_R - t_0}{t_0}$$

Where:
- $t_R$ is the retention time of the main peptide peak.
- $t_0$ is the column void time (time required for an unretained compound to pass through).

An optimal $k'$ value for analytical peptide chromatography ranges between $2.0 \\le k' \\le 10.0$.

---

## Causes of Retention Time Drift

- **Column Temperature Variations**: A $1^\\circ\\text{C}$ temperature change can alter $t_R$ by $1-3\\%$.
- **Mobile Phase Evaporation**: Volatile organic modifier loss alters gradient strength.
- **Column Aging & Silanol Exposure**: Stationary phase degradation shifts retention behavior over time.
