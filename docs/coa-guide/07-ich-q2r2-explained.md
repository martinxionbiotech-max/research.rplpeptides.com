# ICH Q2(R2) Explained: Validation of Analytical Procedures

!!! info "Executive Summary"
    ICH Q2(R2) defines global standards for validating analytical methods across core criteria: Specificity, Linearity, Accuracy, Precision, LOD, LOQ, and Robustness.

## Validation Criteria Matrix

| Validation Parameter | Acceptance Threshold | Purpose |
| :--- | :--- | :--- |
| **Specificity** | Resolution $R_s \\ge 1.5$ from impurities | Ensures no co-eluting peaks |
| **Linearity** | $R^2 \\ge 0.999$ | Verifies proportional response |
| **Repeatability** | Peak Area $\\text{RSD} \\le 1.0\\%$ | Evaluates intra-day precision |
| **Intermediate Precision** | Peak Area $\\text{RSD} \\le 2.0\\%$ | Evaluates inter-day/analyst precision |
