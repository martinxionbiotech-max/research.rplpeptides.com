# Common Synthetic Peptide Impurities: Types, Causes, and Detection

!!! info "Executive Summary"
    Synthetic peptide impurities arise from incomplete coupling reactions, side reactions during cleavage, or environmental degradation.

## Main Impurity Categories

| Impurity Type | Mechanism / Cause | Mass Shift | Chromatographic Behavior |
| :--- | :--- | :--- | :--- |
| **Deletion Peptides $(N-1)$** | Incomplete Fmoc coupling step | $-\\text{Mass of amino acid}$ | Elutes near target peak |
| **Oxidized Peptides** | Methionine/Tryptophan oxidation | $+16\\text{ Da } (\\text{or } +32\\text{ Da})$ | Earlier elution (more polar) |
| **Diastereomers** | Epimerization at $\\alpha$-carbon | $0\\text{ Da}$ (Identical Mass) | Partially resolved peak |
| **TFA Adducts** | Residual trifluoroacetic acid | $+114\\text{ Da}$ | Variable |
