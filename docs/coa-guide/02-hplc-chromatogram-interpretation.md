# HPLC Chromatogram Interpretation: A Practical Field Guide

A chromatogram is a graphical plot of detector response versus time. Interpreting a chromatogram requires evaluating peak symmetry, baseline noise, and signal resolution.

## Signal-to-Noise Ratio (S/N) Formula
$$\text{S/N} = \frac{2H}{h}$$

Where $H$ is peak height from baseline, and $h$ is peak-to-peak noise of the baseline in a blank run.
