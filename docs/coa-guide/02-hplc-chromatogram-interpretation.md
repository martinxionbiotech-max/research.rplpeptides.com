# HPLC Chromatogram Interpretation: A Practical Field Guide

!!! info "Executive Summary"
    A chromatogram is a graphical plot of detector response versus time. Interpreting a chromatogram requires evaluating peak symmetry, baseline noise, and signal resolution.

## Signal-to-Noise Ratio ($S/N$) Formula

$$\\text{S/N} = \\frac{2H}{h}$$

Where:
- $H$ is the peak height from the central baseline to the apex.
- $h$ is the peak-to-peak noise range of the baseline observed in a blank run over a defined window.

According to ICH Q2(R2) guidelines:
- **Limit of Detection (LOD)**: $S/N \\ge 3:1$
- **Limit of Quantitation (LOQ)**: $S/N \\ge 10:1$

---

## Key Features of a Peptide Chromatogram

1. **Solvent Front ($t_0$)**: Initial void peak representing unretained mobile phase and non-retained salts.
2. **Main Target Peak**: Dominant signal representing the primary peptide product.
3. **Impurity Peaks**: Smaller secondary peaks corresponding to deletion sequences, diastereomers, or oxidation products.
4. **Baseline Drift**: Gradual upward or downward slope caused by gradient mobile phase absorbance changes.
