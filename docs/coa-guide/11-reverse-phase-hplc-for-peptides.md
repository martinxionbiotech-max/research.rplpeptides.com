# Reverse Phase HPLC for Peptides: Columns, Mobile Phases, and Ion-Pairing

Reversed-Phase HPLC separates peptides based on hydrophobic interactions between side chains and non-polar stationary phases (C18, C8, C4).

## Pore Size Requirements
For peptides and small proteins, $300\,\text{\AA}$ pore silica columns are required to prevent restricted diffusion inside column pores.
