# Peak Area vs Peak Height in HPLC Purity Calculations

Chromatographic purity calculations use integrated peak area rather than peak height because peak height varies with column degradation and band broadening.

## Mathematical Integration Formula
$$A = \int_{t_1}^{t_2} I(t) \, dt$$
